# مشروع Gym

واجهة موقع النادي الرياضي مبنية باستخدام Nuxt 4 وVue 3، مع الحفاظ على تصميم القالب الحالي.

## التشغيل

```bash
npm install
npm run dev
```

أوامر الإنتاج:

```bash
npm run build
npm run preview
```

## تنظيم المشروع

- `src/pages/`: صفحات الرئيسية، من نحن، الأسعار، المعرض، المدونة، المقال، والتواصل.
- `src/layouts/default.vue`: الهيكل المشترك ورابط تجاوز القائمة إلى المحتوى.
- `src/components/`: مكونات Vue المشتركة للأقسام والنماذج والتنقل.
- `public/`: الصور والخطوط وملفات CSS الخاصة بـ Bootstrap والأيقونات.
- `scss/`: وحدات Sass؛ `style.scss` يجمع تنسيقات القالب و`app.scss` يضم تنسيقات التطبيق ومتغيراته.

يستخدم Sass نظام الوحدات `@use`، ويجمع Nuxt التنسيقات وقت البناء. المسارات القديمة المنتهية بـ `.html` مدعومة كمسارات بديلة، بينما روابط الموقع الداخلية تستخدم مسارات Nuxt.
